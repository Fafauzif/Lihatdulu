# Taste for LihatDulu

This is a repo-specific reading profile of Leonxlnx's Taste skill. See the pinned source in [the skill map](../../../docs/handoff/SKILLS.md). The original instructions live in [UPSTREAM-SKILL.md](UPSTREAM-SKILL.md). This profile uses selected text references. The upstream visual kit, photos, checker and hooks are separate.

1. Identify the shopper's immediate task. Show search, categories, price and results before promotion. Review [layout](references/layout-v4.md) and [cards](references/cards.md) for hierarchy and alignment. Apply the project palette, assets and Vite setup.
2. Put actual catalogue furniture and product information in view. Use existing item imagery and distinguish real photos, rendered examples and new scans. Let prices, dimensions and locations do the talking. Refer to [copy](references/copy.md) and [voice](references/copy-voice.md).
3. Keep actions obvious and polish transitions only where they clarify a change of state. Use [motion](references/motion.md) with reduced-motion support.
4. Run the existing Playwright checks, inspect the first viewport and filters at mobile, compact desktop and wide desktop, and compare before/after with the same fixture. Follow the marketplace workstream for acceptance.

Use Impeccable for a separate critique pass if useful. Use the pinned upstream release separately when you need its full asset or checker kit.
